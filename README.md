# Final IAI

The three course tasks live in separate folders. Open the repository root in your terminal before running their module commands.

| Task | Project | Instructions |
| --- | --- | --- |
| Task 1 | N-Queens: SAT and Min-Conflicts | [task1/README.md](task1/README.md) |
| Task 2 | Tank Battle: Adversarial Search | [task2/README.md](task2/README.md) |
| Task 3 | Kakuro: Constraint Satisfaction | [task3/README.md](task3/README.md) |

Quick start for Task 2 from the repository root:

    python -m pip install -r task2/requirements.txt
    python -m task2.main --headless
    python -m pytest task2/tests -q

Run `python -m task2.main` to open its PyGame interface. Each task's README has its own setup and demo instructions.
